# 공식 사이트 딱지

Google 검색 결과가 공식 홈페이지인지 판별해 딱지로 표시하는 Chrome 확장 프로그램입니다. Upstage Solar API를 이용해 검색 결과를 `공식`, `준공식`, `일반 사이트`로 분류합니다.

## 주요 기능

- 공식 홈페이지에 파란색 딱지 표시
- 공식 배포 채널·공공기관 등 준공식 출처에 초록색 딱지 표시
- 판정이 애매한 경우 실제 페이지 내용을 이용한 2차 검증

## 실행 방법

Node.js 18 이상과 Upstage API 키가 필요합니다.

1. 서버를 실행합니다.

   ```bash
   node server/server.js
   ```

2. 터미널에 Upstage API 키를 입력합니다.
3. Chrome에서 `chrome://extensions`를 엽니다.
4. **개발자 모드**를 켜고 **압축해제된 확장 프로그램을 로드합니다**를 선택합니다.
5. 이 저장소의 `extension` 폴더를 선택합니다.
6. Google에서 검색하면 결과 옆에 딱지가 표시됩니다.

서버는 `http://127.0.0.1:8787`에서 실행됩니다. API 요청 제한 시간은 30초이며, 요청별 소요시간은 서버 콘솔에서 확인할 수 있습니다.

```text
[Upstage API] 1차 분류: 8.42초
[Upstage API] 2차 검증: 14.17초
```

## 폴더 구조

```text
extension/  Chrome 확장 프로그램
server/     Upstage API 연동 서버
```
