# 구라제거기 — AI Builder Sprint 통합본

제목 검증, 광고·피싱 판별, 공식 출처 판별의 세 기능과 이를 한 번에 실행하는 Chrome 통합 확장을 제공하는 저장소입니다.

## 통합 기능

1. **제목·본문 비교**: 검색 결과의 실제 본문을 읽고 제목의 일치·과장·불일치를 표시하며, 글에 들어가면 검색어 관련 근거를 강조합니다.
2. **피싱·광고 위험**: 광고성·피싱·로그인 장벽을 판별하고, 위험 판정 글에 들어가면 의심 문장을 강조합니다.
3. **공식·공신력 출처**: 검색 대상이 직접 운영하는 사이트와 공신력 있는 출처를 구분해 표시합니다.

각 기능은 팝업에서 독립적으로 켜고 끌 수 있습니다. API 키가 저장되어 있으면 Google 검색 결과가 준비될 때 현재 페이지를 자동 분석하며, **현재 검색 페이지 분석** 버튼은 수동 재시도용으로 그대로 제공됩니다.

## 심사용 로컬 기동 실행 가이드

별도 빌드나 패키지 설치는 필요하지 않습니다.

1. 저장소를 내려받습니다.
   ```bash
   git clone https://github.com/kook222/AI-Builder-Sprint.git
   cd AI-Builder-Sprint
   ```
2. Chrome 주소창에서 `chrome://extensions`를 엽니다.
3. 우측 상단의 **개발자 모드**를 켭니다.
4. **압축해제된 확장 프로그램을 로드합니다**를 누릅니다.
5. 내려받은 저장소의 `unified-extension` 폴더를 선택합니다.
6. Chrome 툴바의 구라제거기 아이콘을 열어 Upstage API 키를 입력하고 **저장**을 누릅니다.
7. 사용할 기능의 토글을 켠 뒤 `google.com` 또는 `google.co.kr`에서 검색합니다.
8. 검색 결과가 준비되면 현재 페이지 분석이 자동으로 시작됩니다. 필요하면 팝업의 **현재 검색 페이지 분석** 버튼으로 수동 재시도할 수 있습니다.

별도 FastAPI·Node 서버는 필요하지 않습니다. 통합본의 자세한 구조와 동작은 [unified-extension/README.md](unified-extension/README.md)를 참고하세요.

## 실행·배포 환경 정보

| 항목 | 내용 |
|---|---|
| 서비스 유형 | Chrome Manifest V3 확장 프로그램 |
| 지원 브라우저 | Google Chrome 116 이상 |
| 지원 운영체제 | Chrome을 실행할 수 있는 macOS, Windows, Linux |
| 빌드·런타임 | 별도 빌드 도구, Node.js 서버, Python 서버 없음 |
| 외부 통신 | Google 검색 결과·대상 문서 접근 및 Upstage Solar API 호출을 위한 인터넷 연결 필요 |
| AI 모델 | Upstage `solar-pro3` |
| 로컬 로드 경로 | `unified-extension/` |

배포 서버에 의존하지 않으므로 저장소만 내려받아 Chrome에 압축 해제 확장으로 로드하면 재현할 수 있습니다.

## 환경변수 및 API 키 정보

- 운영체제 환경변수와 `.env` 파일은 사용하지 않습니다.
- 필요한 비밀값은 **Upstage API 키 1개**이며, 확장 팝업에서 직접 입력합니다.
- 키는 `chrome.storage.local`의 확장 전용 저장소에만 보관되고 저장소, 페이지 DOM, 분석 대상 사이트에는 기록하지 않습니다.
- API 키가 없으면 분석을 시작하지 않고 팝업에서 키 입력 안내를 표시합니다.
- 대회 안내에 따라 Upstage API 키는 주최 측이 보유하므로 별도 테스트 키 제출이 필요하지 않습니다.

## 기능 재현 시나리오

1. Google에서 `코스피 전망`처럼 뉴스 결과가 나오는 검색어를 입력합니다.
2. 검색 결과 아래 제목·본문 비교 결과와 광고·피싱 위험 판정이 자동으로 표시되는지 확인합니다.
3. 공식·공신력 출처 점에 마우스를 올려 확신도와 판단 근거를 확인합니다.
4. 분석된 일반 기사 링크를 열어 검색어·판정 근거 문장이 본문에서 강조되는지 확인합니다.
5. Google 검색의 다음 페이지로 이동해 새 페이지 결과가 별도 분석되는지 확인합니다.

나무위키, Wikipedia, PDF, Google 광고 결과는 분석 대상에서 제외합니다. 사이트가 로그인을 요구하거나 자동 수집을 차단하면 해당 결과에 수집 실패 사유를 표시하며, 다른 결과의 분석은 계속 진행합니다.

## 실행 문제 해결

- 코드를 갱신한 경우 `chrome://extensions`에서 구라제거기의 **새로고침**을 누른 뒤 Google 검색 페이지도 새로고침합니다.
- 자동 분석이 시작되지 않으면 API 키 저장 여부와 기능 토글을 확인한 후 **현재 검색 페이지 분석**을 누릅니다.
- Chrome 116 미만에서는 공식 딱지의 판단 근거 Popover가 지원되지 않으므로 최신 Chrome을 사용합니다.

## 보존된 원본 구현

세 기능의 확장 구현은 원형을 확인할 수 있도록 각각 별도 보존했습니다.

```text
gurajegeo-title/   제목·본문 비교 원본
fact-trace/        피싱·광고 위험 원본
extension/         공식 출처 원본 확장
unified-extension/ 실제 통합 실행본
```

기존 폴더는 각 기능의 원형과 개발 이력을 확인하기 위한 것이며, 통합 사용 시에는 `unified-extension/`만 Chrome에 로드합니다.
