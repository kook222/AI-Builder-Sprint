# 구라제거기 통합 Chrome 확장

`kook2`, `subin`, `official_thagji` 세 브랜치의 기능을 하나의 Manifest V3 확장으로 조정한 실행본입니다. 원본 디렉터리는 수정·삭제하지 않고 별도로 유지합니다.

## 설치 및 실행

1. Chrome 주소창에 `chrome://extensions`를 입력합니다.
2. 우측 상단 **개발자 모드**를 켭니다.
3. **압축해제된 확장 프로그램을 로드합니다**에서 이 `unified-extension` 폴더를 선택합니다.
4. 구라제거기 아이콘을 눌러 Upstage API 키를 입력하고 **저장**을 누릅니다.
5. 원하는 기능만 켭니다.
6. Google 검색 결과 페이지에서 **현재 검색 페이지 분석**을 누릅니다.

코드를 수정했다면 `chrome://extensions`에서 구라제거기의 **새로고침** 버튼을 누른 뒤 검색 페이지도 새로고침합니다.

## 팝업에서 보이는 상태

팝업은 세 기능을 하나의 카드로 섞지 않고 각각 표시합니다.

- 제목·본문 비교: 본문 수집 → AI 판정 → 결과 표시
- 피싱·광고 위험: 본문 수집 → 위험 판정 → 의심 문구 준비
- 공식·공신력 출처: 결과 분류 → 필요 시 본문 2차 검증 → 딱지 표시

각 카드에는 현재 단계, 완료/전체 개수, 진행 막대, 최근 설명이 표시됩니다. 실행 중에는 중복 실행 버튼이 잠기며, 기능 토글을 끄면 해당 기능의 진행 작업과 화면 요소만 정리됩니다.
팝업은 Chrome의 400×600px 영역 안에 세 진행 카드와 실행 버튼이 함께 보이도록 구성했습니다.

## 화면 UI 소유권

- 제목 기능은 검색 결과 제목 아래의 분석 카드와 기사 본문의 청록색 근거 강조만 소유합니다.
- 위험 기능은 제목 옆 위험 배지, 상단 경고 띠, 빨강·연분홍 위험 문장 강조만 소유합니다.
- 공식 기능은 제목 옆 파랑·초록 출처 점만 소유합니다.
- 위험 배지와 공식 점은 공용 `result-hub` 안에서 함께 배치되어 서로 밀어내거나 덮지 않습니다.
- 모든 삽입 요소는 `data-gurajegeo-ui`와 기능별 접두사로 범위가 제한됩니다.

## 데이터와 API 키

- API 키는 `chrome.storage.local`의 확장 전용 설정에만 저장하며 DOM이나 사이트 요청에 넣지 않습니다.
- 기사 전체 본문과 Solar 원문 응답은 저장하지 않습니다.
- 현재 실행의 진행률, URL 연결 정보, 검증된 판정·하이라이트 위치처럼 기능에 필요한 짧은 런타임 정보만 `chrome.storage.session`에 보관합니다.
- 별도 로컬 서버는 사용하지 않으며 Service Worker가 Solar Pro 3를 직접 호출합니다.
- Solar 호출은 세 기능이 공용 동시성 제한을 사용하되, 서로 독립적인 작업으로 병렬 실행됩니다.
- 긴 분석 중에는 공용 heartbeat로 Service Worker를 유지하고, 단일 요청은 Chrome 제한 전에 중단해 최대 3회 재시도합니다.
- 브라우저가 작업 도중 Service Worker를 다시 시작하면 이전 `분석 중` 상태를 오류로 복구해 재실행할 수 있게 합니다.

## 분석 범위

- 사용자가 실행한 현재 Google 검색의 `q + start + tbm + udm` 조합만 활성화합니다. 페이지 번호와 웹·뉴스·이미지 검색 영역이 달라져도 실행 결과가 섞이지 않습니다.
- 현재 화면의 수집 가능한 일반 검색 결과 전체를 대상으로 하며 광고 검색 결과는 제외합니다.
- 나무위키, Wikipedia, PDF는 세 기능의 검색 결과 분석에서 제외합니다.
- 제목 기능의 비활성 본문 수집 탭에서는 위험 기능을 실행하지 않습니다.
- 직접 연 글에서는 직전 검색 실행과 URL이 연결된 경우 제목 근거를 자동 강조하고, 위험 판정 기록이 있으면 위험 문장을 자동 강조합니다.

## 파일 구조

```text
unified-extension/
├── manifest.json
├── background.js          # 통합 명령과 세 기능 시작 조정
├── popup.html/css/js      # API 키, 독립 토글, 통합 진행 UI
├── shared/
│   ├── settings.js        # 공용 설정
│   ├── progress.js        # 세션 진행 상태
│   ├── solar-gate.js      # API 공용 동시성 제한
│   ├── service-worker-keepalive.js # 장기 작업 수명주기
│   ├── url-safety.js      # 외부 수집 URL 경계
│   └── content.css        # 검색 결과 공용 배치 영역
└── features/
    ├── title/             # 제목·본문 비교
    ├── risk/              # 피싱·광고 위험
    └── official/          # 공식·공신력 출처
```

## 권한 설명

- `storage`: API 키·토글과 실행 중 진행 메타데이터
- `tabs`, `scripting`: 실제 렌더링된 기사 본문 수집과 개발 중 열린 탭의 스크립트 재주입
- `http://*/*`, `https://*/*`: 사용자가 분석한 검색 결과 페이지의 본문 접근

확장 배포 전에는 Chrome Web Store 정책에 맞춰 호스트 권한을 선택적 권한으로 좁히는 작업을 별도로 검토할 수 있습니다.
